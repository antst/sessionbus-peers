# Sessionbus peers v0.5.2

This release will make the installed peer build identifiable without starting
the native product. Every public peer command accepts `--version` and prints
the peer release with its exact source revision. The existing native short
version spelling is also intercepted per product: `-v` for Claude, Grok, Kilo,
OpenCode, Qwen, Pi and OMP, and `-V` for Codex.

Use `--native-version` when the native product's own version is needed. This
escape is available only to ordinary interactive launches; lane workers reject
it, and private aliases keep their closed argument surfaces.

Development builds identify themselves as `development`. Stable archive builds
require the tag, central `RELEASE_VERSION`, Claude manifest and Codex plugin
base to agree. Each archive and permanent product package includes `SOURCE.txt`
with the full source revision.

This file describes prospective v0.5.2 behavior. It does not mark the release
as published.
