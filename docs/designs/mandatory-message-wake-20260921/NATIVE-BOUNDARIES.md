# Mandatory message wake: native boundaries

Status: source candidate, 2026-09-21. This table defines the current delivery contract for all eight products. Historical FIFO or `idle_message` observations in product ledgers remain evidence for their cited builds; they are not current operating advice.

Every lane message starts native work or is retained by the daemon for an automatic next managed run. For lanes, `queued_for_next_turn` means bounded daemon retention after a definite pre-submission refusal; the later native delivery and outcome belong to the managed Run record, not a second sender receipt. For interactive peers, the same disposition means the product owner accepted bounded input and owns automatic native scheduling and correlation. Neither receipt is durability or model consumption, and neither accepted message may be resent. Product wrappers must never return NotRunning after a native write or enqueue might have occurred.
