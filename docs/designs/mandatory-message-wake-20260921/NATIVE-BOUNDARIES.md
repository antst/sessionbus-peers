# Mandatory message wake: native boundaries

Status: source candidate, 2026-09-21. This table defines the current delivery contract for all eight products. Historical FIFO or `idle_message` observations in product ledgers remain evidence for their cited builds; they are not current operating advice.

Every lane message starts native work or is retained by the daemon for an automatic next managed run. The daemon's `queued_for_next_turn` receipt means bounded, in-memory scheduled retention after a definite pre-submission refusal. It is not native admission, durability, or model consumption. Product wrappers must never return NotRunning after a native write or enqueue might have occurred.
