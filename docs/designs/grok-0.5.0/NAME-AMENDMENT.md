# Initial Grok name

Selected 2026-09-10, based on dev2-input/INITIAL-NAME-CLAIM.md. Native GROK_SESSION_ID supplies identity. A launch name is applied to the first valid managed native-helper initialization under this private launch, once only. Retained normal startup/new traces show initial helper initialization first; they do not prove every abnormal scheduling case or interactive resume composition. Installed acceptance must compare actual native selected identity for fresh/resume and later /new, without claiming a universal scheduling theorem.

Use one exclusive-create claim file in the existing launcher-owned runtime directory; no new endpoint, process, session lock, identity resolver or roster election. This is a one-shot name-application claim, not a guard on native session ownership or resumption. Directory is private to the actual launch and removed with its ordinary cleanup. Validate managed activation/native session ID/launch binding before claiming; create an empty mode0600 file with O_CREATE|O_EXCL. The claim needs no stored ID, title, result or conversation data; the winning helper already has its native ID in memory. Ordinary/inert helpers never claim. Other errors are errors, not permission to act as winner.

Make the claim before the helper completes MCP initialize. The winner performs native same-ID rename asynchronously after returning initialize so native initialization is never blocked by an ACP operation that requires it to finish. Reuse that helper's normal ACP observer; do not create another Caller or a naming-only process. Later /new helpers never apply the inherited launch name. Native subsequent title changes remain authoritative. Failed rename reports failure and never transfers the claim to a later session or publishes a fabricated title.

Native selectors are still forwarded to Grok verbatim; --resume without a value keeps its native most-recent behavior. Controlled tests cover two helpers claiming, invalid/ordinary helper not consuming claim, initialize completion before held native rename, native failure, and separate launch directories. Installed fresh/resume/new rows bind native IDs, requested initial name and subsequent native titles. An observed initial-selection mismatch is a failure to fix, not evidence to relabel.
